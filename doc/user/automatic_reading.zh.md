# 自动阅读

在阅读器菜单中启动自动阅读，或将阅读设置中的长按动作设为「开始／停止自动阅读」。分页模式按翻页间隔推进，连续／瀑布流模式使用平滑或分步滚动。

自动阅读默认等待图片加载成功，失败时也会等待，以便手动重试。需要持续阅读时，可在「设置 → 阅读」或漫画的阅读设置中开启「自动阅读时跳过不可用图片」。失败图片按正常翻页／滚动节奏跳过；加载中的图片等待设定时间后继续。等待时间默认为 10 秒，可设置为 1–60 秒。

图片等待只计算自动阅读处于前台、没有操作阻塞时的时间。触摸／缩放手势进行中、长按、打开菜单和切到后台都会暂停推进；重新开始等待时不会补算后台时间。连续／瀑布流在手势结束后可保持放大继续滚动，设置速度按屏幕距离计算，放大的末页显示完后才停止或跨章；分页画廊在主动放大时仍暂停自动翻页。换到另一页或另一组可见图片后重新计时；重新加载失败图片也会开始新的等待。

「自动继续下一章节」决定到达章节末尾后是否继续。跳过选项只处理图片，章节列表或章节内容加载失败时仍需重试。全局、当前设备和单部漫画设置沿用现有的继承规则。
