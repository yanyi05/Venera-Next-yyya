# yyya 分支阅读工具

本轮以原作者 v1.18.3 为基础，保留现有图片遮罩功能。验证范围按要求限定为 Windows 与 iPhone。

## 阅读器底部工具

- **刷新图片**：选择图片后开始刷新，解码成功才提示完成；失败会显示错误，可重新点击重试。刷新版本按图片保存，不会同时刷新整章。
- **白边裁剪**：选择关闭、自动识别或手动设置四边比例。设置对当前漫画生效；关闭即可恢复完整原图。裁剪只用于显示，下载、缓存原图与导出的原文件不变。
- **识别文字与翻译**：仅在支持实况文本的 iPhone 上显示。选择已加载的图片，识别后长按文字，在系统菜单中复制或翻译；支持双指缩放。识别和翻译的语言及可用性由 iOS 决定，本应用没有配置收费翻译接口。

裁剪默认关闭。自动裁剪会保留内容周围的小边距，每边自动移除不超过 20%；手动每边最多 40%。为保留现有遮罩位置，带遮罩的图片保持完整画面。超过 1600 万像素的图片、动图，以及裁剪解码器不支持的格式也会保留原图。文字识别使用最长边 4096 像素的预览，极长条图上的小字可能识别不清。

## 空间管理

打开“设置 → 应用 → 空间管理”：

1. 查看按漫画分组的临时缓存，勾选需要清理的项目。
2. 选择保留最近 7 天、30 天使用的缓存，或不保留近期缓存。
3. 查看预计释放空间，确认后清理。确认期间刚读取或重新写入的缓存会保留。
4. 可另外扫描下载与本地漫画的占用。该扫描只查看空间，不提供删除漫画操作；不可访问的目录会显示“无法读取”。

旧版本产生的缓存与封面可能集中显示为“封面、旧版本及其他临时缓存”。清理不会删除已下载漫画、收藏、阅读进度或原文件。

## 启动诊断与恢复

初始化失败时，可复制或分享脱敏后的诊断详情，包含应用构建版本、失败阶段和上次启动阶段。
可以选择“下次启动停用已安装漫画源”，然后完全关闭并重新打开应用。这个选项不会删除漫画源文件或收藏；恢复正常加载时，在“设置 → 应用”关闭恢复模式，再重启应用。

该恢复选项用于绕过已安装源脚本的加载；不能处理所有原生库、签名校验或 iOS 在 Dart 启动前发生的崩溃。白屏直接退出仍应保留系统 `.ips` 记录用于定位。

## 内存与预加载

预加载优先沿当前阅读方向进行；快速跳页时减少额外预读。手机的预加载上限为 6 页，解码缓存上限为 128 MiB；系统内存告警后暂停预读并降低缓存上限，冷却后恢复。切到后台也会暂停预读。当前正在显示的图片不会主动清空。

这些上限是当前实现的策略，不代表已经测得具体的帧率、耗电或温度改善，仍需在实际设备上对照验证。

## 网站验证入口

“发现”页面顶部的地球按钮和加载失败页的“网站验证”按钮，会打开当前漫画源提供的网页登录入口。完成验证、保存成功后返回漫画列表并重新加载，不需要先进入漫画源设置。分类页顶部也保留该入口；未提供网页登录地址的源不显示按钮。

从历史记录继续阅读时，漫画信息加载失败页和章节加载失败页也有“网站验证”按钮，返回后会重试对应加载。在线漫画的阅读页顶部保留地球按钮，可随时打开当前源的内置浏览器验证入口。

阅读器会取消手指移动超过 8 个逻辑像素的点击，也会在滚动开始或画面继续滚动时取消等待中的菜单点击，减少上下滑动时误唤出菜单。正常轻点和双击缩放仍保留。

Windows 内置浏览器继续使用固定的应用数据目录保存浏览器会话。传给应用网络层的 Cookie 保留域名、路径、有效期、Secure 和 HttpOnly 属性；源的登录成功判断也会在网页加载完成后再检查一次。

保存会话不能改变站点设置的验证期限，也不能保证从浏览器取出的验证 Cookie 一定被应用网络请求接受。截图中的包子源还识别网站自有的 gatekeeper 验证，不能将所有验证都视为 Cloudflare。此轮没有更改用户安装的漫画源脚本，没有代填 User-Agent 或改动代理；没有实现常驻网页阅读模式，也未在真实站点验证重复挑战频率。

## 更新与构建

应用更新检查与下载入口指向 `yanyi05/Venera-Next-yyya`。尚未发布安装包时，不会将“没有 Release”当作检查失败。
“设置 → 关于”另保留原作者更新入口；原版安装包不会包含本分支的自定义功能。

GitHub Actions 新增手动工作流“yyya Windows 与 iPhone 构建”，仅构建这两个平台，不发布 Release。iPhone IPA 仍需自行签名安装；Windows 构建沿用现有安装器与压缩包流程。

Windows 本机启动检查使用调试构建参数 `VENERA_TEST_DATA_ROOT` 指定独立数据目录，避免升级日常使用的数据。正式构建忽略此参数，使用正常应用数据目录。
